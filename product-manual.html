OVERVIEW

产品概述

PCT-100型温湿度控制器是一款基于ESP32微控制器的智能物联网设备，集成DHT22温湿度传感器、光敏电阻传感器、双路继电器输出及WS2812 RGB状态指示灯，通过WiFi连接网络并使用MQTT协议与云平台通信，广泛应用于智能温室、机房环境监控、仓储温湿度管理及物联网教学实训等场景。

🎯

设计理念

以"感知—控制—通信"为核心架构，将传感器数据采集、自动控制逻辑、远程通信整合为一体化嵌入式方案，便于二次开发与系统集成。

🏭

适用场景

适用于智能温室大棚环境调控、数据中心机房温湿度监控、仓库存储环境管理、物联网教学实训及智能家居DIY项目。

📋

涵盖技术

嵌入式开发(Arduino/ESP32)、传感器驱动、FreeRTOS实时操作系统、WiFi网络编程、MQTT物联网协议、JSON数据交换。

SYSTEM

系统组成

设备采用模块化软件架构，各功能模块独立封装，通过FreeRTOS双线程调度实现高效并发处理。

🌐

WiFi管理模块

非阻塞状态机设计，支持自动扫描、密码输入、配置保存/清除、断线自动重连。首次使用通过串口选择WiFi网络并输入密码。

📡

MQTT通信模块

基于PubSubClient库，支持多配置文件管理（生产/测试环境一键切换）、定时状态上报、JSON格式指令接收与解析。

🌡

传感器模块

DHT22温湿度传感器驱动 + 光敏电阻ADC采样。温度精度±0.5°C，光照采样值0-4095，支持阈值越界自动报警。

⚙

控制执行模块

双路继电器分别控制灯光与风扇。自动模式下根据传感器阈值自动开关；手动模式下通过按键或MQTT远程独立控制。

OPERATION

工作模式

设备支持自动与手动两种工作模式，通过KEY2按键或MQTT远程指令切换。

🔃

自动模式（默认）

系统根据预设阈值自动控制：当光照ADC值超过光照阈值时自动开灯；当温度超过温度阈值时自动开启风扇。两个阈值均可通过串口或MQTT远程调整并持久化保存。

👓

手动模式

通过KEY2按键循环切换4种状态：全关 → 风扇开 → 灯光开 → 全开。也可通过MQTT下发 set_relay 指令独立控制每路继电器。RGB LED实时指示当前模式与报警状态。

MQTT PROTOCOL

MQTT 通信协议

设备通过MQTT与云端交互，以下为消息主题定义和控制指令格式（设备ID为配置值，非固定）。

📤

上行主题（设备→云端）

chemctrl/{设备ID}/status

JSON格式定时上报，包含温度、光照、模式、继电器状态、当前阈值等信息。

📥

下行主题（云端→设备）

chemctrl/{设备ID}/command

支持的指令：set_relay（控制继电器）、set_mode（切换模式）、get_status（查询状态）、set_threshold（设置阈值）、reboot（重启）。

SERIAL CLI

串口命令行

通过USB串口（115200bps）连接设备，可使用以下CLI命令进行调试和配置。

clearwifi清除已保存的WiFi配置，下次启动重新扫描
showwifi显示当前WiFi连接状态和IP地址
reboot重启设备
help显示串口命令帮助
mqtt set server <地址>设置MQTT服务器地址
mqtt set port <端口>设置MQTT端口号
mqtt set username <用户名>设置MQTT认证用户名
mqtt set password <密码>设置MQTT认证密码
mqtt save保存当前MQTT配置到Flash
mqtt show显示当前MQTT配置信息（密码不显示明文）
mqtt reconnect断开并重新连接MQTT服务器
mqtt config save <名称>将当前配置另存为命名配置文件
mqtt config load <名称>加载指定的配置文件
mqtt config list列出所有已保存的配置文件
SAFETY

安全防护设计

设备在硬件和软件层面均设计了安全防护机制，确保长期可靠运行。

⚡

电气安全

继电器输出与主控电路光耦隔离；电源输入端加装自恢复保险丝；接线端子采用防呆设计，防止反接。

🔔

阈值报警

温度/光照越界时RGB LED变色报警（红色=温度越界，黄色=光照越界，紫色=双重越界）；同时通过MQTT上报报警状态。

🔑

通信安全

MQTT连接支持用户名/密码认证；WiFi密码和MQTT凭证加密存储于NVS分区；串口调试命令仅本地有效。

🔃

故障恢复

WiFi断线自动重连；MQTT断线自动重连（间隔5秒）；Watchdog定时器防止程序死锁；配置数据CRC校验。
